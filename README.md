# PDF Toolkit

محرر PDF للكمبيوتر بواجهة حديثة (Python + PySide6 + PyMuPDF) — يعمل على ويندوز وماك ولينكس.

## المزايا

- **قراءة**: تمرير مستمر، تكبير بـ Ctrl+عجلة الماوس، ملاءمة العرض/الصفحة، وضع قراءة ليلي، تبويبات لعدة ملفات، فهرس، مصغّرات
- **بحث** داخل المستند مع تلوين النتائج
- **تحديد ونسخ** النص
- **تعليقات**: تظليل، تسطير، شطب، تعليقات (ملاحظات)، رسم حر، مستطيل، دائرة، خط، سهم
- **تعديل**: إضافة نص (يدعم العربية)، تعديل سطر نص موجود، إدراج صورة، توقيع مرسوم، إخفاء نهائي (Redact)
- **إدارة الصفحات**: تدوير، حذف، تكرار، إدراج صفحة فارغة، إعادة ترتيب بالسحب، دمج، استخراج، إدراج ملف PDF
- **تراجع/إعادة** لكل العمليات
- حفظ، حفظ باسم، حفظ بحجم أصغر، **كلمة مرور**، تصدير الصفحات كصور
- ثيم فاتح وداكن، واجهة عربية/إنجليزية، سحب وإفلات الملفات

## التشغيل

```bash
pip install -r requirements.txt
python main.py            # أو: python main.py ملف.pdf
```

## الاختبارات

```bash
pip install pytest
pytest                    # الاختبارات تعمل بدون شاشة (offscreen)
```

لحفظ لقطات شاشة للواجهة أثناء الاختبار: `SCREENSHOT_DIR=screenshots pytest`

## بناء ملف exe لويندوز

تلقائيًا من GitHub: كل push على `main` يشغّل الاختبارات ثم يبني `PDFToolkit.exe`، وتجده في **Actions ← آخر تشغيل ← Artifacts**. وعند رفع tag مثل `v1.0.0` يُرفق الملف في **Releases**.

محليًا:

```bash
pip install pyinstaller
pyinstaller --noconsole --onefile --name PDFToolkit main.py
```

## هيكل المشروع

```
main.py                  # نقطة التشغيل
pdftool/
├── document.py          # محرك PDF (بدون واجهة): فتح/حفظ/تعليقات/صفحات/تراجع
├── view.py              # عارض الصفحات والأدوات (تمرير مستمر، تحديد، رسم)
├── panels.py            # المصغّرات والفهرس وقائمة الملاحظات
├── mainwindow.py        # النافذة الرئيسية والتبويبات وأشرطة الأدوات
├── dialogs.py           # التوقيع، الدمج، التصدير، الخصائص
├── theme.py / icons.py  # الثيمات والأيقونات
└── i18n.py              # الترجمة العربية
tests/                   # اختبارات المحرك + اختبار شامل للواجهة
```
